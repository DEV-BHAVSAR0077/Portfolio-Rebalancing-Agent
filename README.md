# Portfolio Rebalancing Suggestion Tool using Pandas + LLM Reasoning

## Overview
This project implements an Agentic AI-based portfolio rebalancing system. Pandas is used for quantitative portfolio analysis, while an LLM acts as a reasoning agent to generate explainable investment recommendations using multi-step prompt engineering.

## Key Features
- Agentic AI reasoning
- Portfolio drift detection
- Explainable financial recommendations
- Optional RAG-based knowledge usage

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Add your OpenAI API key in app.py

3. Run:
   python app.py
